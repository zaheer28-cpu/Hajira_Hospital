# Hajira Hospital

A modern, responsive healthcare and hospital management web application built with Next.js, React, and Tailwind CSS.

## Features

- **Areas of Care & Specialties**: Detailed department overviews with interactive previews.
- **Doctor Directory & Profiles**: Meet the medical team with experience highlights and bio modals.
- **Appointment Booking**: Streamlined patient appointment booking and scheduling flow.
- **Patient Resources & Checklist**: Preparation checklist, visitor guidelines, and emergency info.
- **Interactive Animations**: Smooth scroll animations, spotlight cards, and statistics counter.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/), Lucide Icons
- **Language**: TypeScript

## Build for Production

```bash
npm run build
npm run start
```
